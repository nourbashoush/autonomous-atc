# YOLO Aircraft Detection

## Overview

This folder contains the scripts and dataset used to train the YOLOv8 computer vision model for detecting aircraft on the airport radar display, as described in Chapter 6 of the thesis.

The goal of this component was to train a lightweight, real-time detection model that identifies when an aircraft enters a protected runway zone—used for enforcing runway access rules in the simulation.

## Structure
- `generate_dataset.py`: Script used to generate the full dataset of synthetic radar images, with aircraft placed at random locations within a predefined bounding region.
- `dataset/`: Contains the generated image dataset and corresponding YOLO-formatted label files (not included due to file size restrictions).
- `runs/`: Stores the results of YOLO training, including metrics, visualisation outputs, and model checkpoints (automatically generated by the Ultralytics framework).

## Training & Testing

> [!NOTE]
> The actual training of the YOLO model was performed using the Ultralytics YOLOv8 CLI, not from within this folder.

To retrain the model or test on the dataset, use the following Ultralytics CLI command:
```bash
yolo task=detect mode=train model=yolov8n.pt data=dataset.yaml epochs=50 imgsz=640
```
The dataset YAML file and folder structure were formatted to be compatible with the Ultralytics standard.
